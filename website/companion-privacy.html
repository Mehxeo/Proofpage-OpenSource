Browser companion privacy

Updated October 17, 2026 · Created by Utsav Das

The companion’s single purpose is to save user-reviewed visible page text to the user’s local Proofpage library.

What it reads

Only when you click Preview, the extension reads the active page’s title, URL and visible text. It excludes form fields, hidden elements, scripts and iframe contents. It removes URL query strings, fragments and embedded credentials. Visible page text can still contain personal or sensitive information. Review and remove it before saving.

Where data goes

Save sends reviewed text to your paired Proofpage app on 127.0.0.1. Download JSON saves it as a file on your computer. The extension does not send page content to Proofpage servers, advertisers, analytics services, or AI providers. Later sharing or model use inside Proofpage is controlled separately by you.

Storage and permissions

Chrome local extension storage holds the app port and an import-only pairing token. It does not sync them to your Google account. The popup holds page text temporarily until closed. The activeTab and scripting permissions allow reading the clicked page; storage remembers the connection; optional localhost access enables direct saving. No cookies, password, browsing-history or background collection permissions are requested.

Your controls

Preview and edit before saving. Disconnect in Proofpage Settings or restart Proofpage to invalidate the connection. Remove the extension to remove its local connection settings. Imported text and downloaded files remain until you delete them in the app or filesystem. Uninstalling the extension does not delete these copies.

Use and contact

Data is not sold, used for advertising, creditworthiness, or unrelated purposes. Use of data complies with the Chrome Web Store User Data Policy, including Limited Use requirements. For questions, use the project’s issue tracker. Do not include private page text or credentials in public issues.
