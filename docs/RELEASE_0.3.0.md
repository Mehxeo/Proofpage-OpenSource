# Proofpage 0.3.0 — Keep the file, search the contents

- Save original PNG, JPEG, WebP, and PDF bytes, preview images, and export original-file bundles.
- Offline image OCR, selectable PDF text extraction, and OCR for scanned PDF pages. Desktop downloads include engines and models.
- Save a public image or PDF directly from the companion, without downloading it first. Requires companion 0.3 and app 0.3; the store's submitted 0.2.2 package is still separate.
- Watch image/PDF URLs hourly and import media from watched folders. Changed captures preserve original bytes, extracted text, history, and receipts.
- Bundles include page-level extraction methods and the original SHA-256. Failed extraction retains the file.

See [Media and automation](MEDIA.md) for limits. Extraction is local, bounded to 20 pages/500,000 characters/90 seconds, and may contain OCR errors. Public file collection does not use browser login cookies. Keep the app running for schedules.
