# What to build next

Ideas, not shipped features or delivery promises. Prefer improvements that help people finish a real evidence workflow.

1. **Collections and tags:** group evidence by project and filter both search and quote checks to a collection. Success: a researcher can keep two investigations separate without two workspaces.
2. **A browser capture extension:** deliberately save the page a user can see, with a preview of included content and explicit user-attested provenance. Never silently collect logged-in sessions or credentials.
3. **Dataset proof bundles:** package all selected revisions, receipts and a single offline verification report. Success: a reviewer can audit an exported training dataset without the original workspace.
4. **Change digests:** summarize watched-page changes locally, then offer explicit opt-in delivery. Avoid notification noise and never send private source text by default.
5. **Safer updates and recovery:** an in-app version notice, verified downloads, pre-migration backups and recovery guidance. Keep signing and platform checks as release gates.
6. **Optional local semantic search:** improve paraphrase retrieval with an explicitly downloaded local model. Measure retrieval quality before adding complexity; preserve lexical search and exact citations.

Before expanding collection coverage, prioritize user feedback, replay fixtures for more content types, accessibility checks, and testing real archive imports. Open [an issue](https://github.com/Mehxeo/Proofpage-OpenSource/issues) with the workflow you could not complete.
